# Skill: changelog-update

Objetivo: actualizar `CHANGELOG.md` sin perder historia.

## Reglas operativas

1. Nunca borrar entradas historicas.
2. Priorizar append de secciones nuevas.
3. Incluir fecha absoluta (YYYY-MM-DD) y objetivo de sesion.
4. Registrar decisiones tecnicas y pendientes inmediatos.
5. Si hay pivote de alcance, declararlo explicitamente y marcar lo pausado.

## Plantilla minima

- Fecha/sesion
- Objetivo
- Cambios implementados
- Decisiones tecnicas
- Pendientes inmediatos
- Riesgos/bloqueos
- Como retomar rapido
